# QuickNotes

QuickNotes is a small, browser-based note-taking app for capturing thoughts and keeping them organized. Add notes under Personal, Work or Study, search your collection, and return to saved notes after refreshing the page.

## Features

- Add notes with a category and readable creation date.
- Validate notes so they are not empty and stay within 200 characters.
- Search note text without case sensitivity.
- Delete individual notes.
- Save notes in the browser with localStorage.
- Use the responsive layout on desktop and mobile screens.

## Run locally

Open `index.html` in a modern web browser. No package installation or build step is required. Notes are stored in that browser's localStorage.
